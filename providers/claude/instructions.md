# Claude and Productive

The Productive build includes Productive's remote MCP endpoint. In Claude chat or Cowork, add/connect Productive from the plugin's Connectors tab using the customer's own account. In Claude Code use the host's MCP authentication controls. Select the intended organisation during authorisation. Installation alone does not authenticate the connection.

Reuse an existing Productive connection if it already provides the tools; avoid duplicates. There is no separate Work with Philo login. If activation is needed, follow the setup skill's invitation lookup or manual email instructions, then resume connection. Philo provisions the account and relevant project/task access.

Start with "Use Work with Philo to get me connected and show what needs my attention." Where commands are available, setup is /work-with-philo:setup. Do not assume automatic setup invocation.

Never request passwords, tokens, or staff credentials in chat. Use only tools available on this Claude surface. Automatic reminders are not enabled; offer manual check-ins.
