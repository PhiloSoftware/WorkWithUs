name: check-in
description: Check current Philo tasks and feedback in Productive to identify the next useful action. Use for a Philo progress check or what needs attention today.
---

Read [the working agreement](references/working-agreement.md), [Productive operations](references/tools.md), [assignment format](references/assignment-format.md), and [provider guidance](references/provider.md).

Resolve Productive identity and query assigned tasks using available schema filters. Check issued Philo briefs and relevant comments. Use actual due dates, supplied dependencies, and verified owner requests to identify useful work; do not invent priority or effort.

Do not chase closed/withdrawn tasks or submissions waiting for Philo without later owner feedback. Respect follow-up dates or snoozes available in the agreed task context. Do not claim persistent preferences exist where none have been saved.

For an explicit check with no actionable work, say so briefly. Offer to resume through [work-with-philo](../work-with-philo/SKILL.md).

Automatic scheduling is not implemented. Do not create schedules, promise background checks, or imply installation enables notifications.
