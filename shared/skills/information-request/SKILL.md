Read [the working agreement](references/working-agreement.md), [Productive operations](references/tools.md), [assignment format](references/assignment-format.md), and [provider guidance](references/provider.md). Load the task and this customer's saved comments even if invoked directly. Require an issued information_request brief; otherwise use [task selection](../work-with-philo/SKILL.md).

Work through issued question IDs. Help locate information using authorised tools. Clarify ambiguous answers without repeating answered questions for the current version.

For each question record answer, outcome (answered, unknown, unavailable, needs_clarification), evidence, provenance, and customer confirmation. Never replace a required fact with an unconfirmed AI deduction.

With permission to save progress, append draft comments using the shared format after re-reading the brief and reports. If an answer is unavailable, preserve the explanation and continue independent questions. Save agreed blockers and proposals separately.

Show the report with unanswered questions and limitations. Follow the working agreement's confirmation and submission steps. Never mark unknown facts answered simply to claim completion.
